## 中文

### 0.7.0 · 账户连接与授权读取

- 在「设置 → 服务接入」新增 Codex、Claude 的「连接现有账户」「浏览器登录」「取消登录」和「断开连接」。浏览器登录由已安装的官方 CLI 发起，无需手动复制 Token。
- 连接后直接查询账户额度、已用/剩余比例与服务提供的重置时间；Token、模型明细和参考费用继续由本机日志统计。
- 授权读取按服务单独开启。取消、超时和断开后不会被迟到的登录结果重新连接；切换来源会清除旧额度，避免混用不同账户。
- 凭证仍由官方工具保存与续期，NowBar 不保存密码、不改写共享凭证。Claude 仅在主动连接时允许请求钥匙串访问，后台刷新不会弹出授权窗口。
- 未登录、授权过期、权限不足、服务限流或未提供额度时，显示明确状态，不把缺失数据当作零。
- 保留原有 Codex CLI、Claude 桌面版/状态栏接入。Grok Bot 继续读取桌面应用的已有登录，本版未加入 Grok Bot 浏览器授权。

### 安装与升级

下载 `NowBar-0.7.0-macOS-arm64.zip`，解压后退出旧版，用新的 `NowBar.app` 替换「应用程序」中的旧应用，再重新打开。已有设置与本机历史保留。

适用于 **Apple Silicon（M 系列芯片）与 macOS 14 或更新版本**。版本号 **0.7.0（build 22）**。安装包采用临时签名，尚未经过 Apple 公证；附 SHA-256 校验文件。应用会提示新版，安装仍需手动替换。

### 说明与验证范围

额度接口属于兼容接入，服务端变化可能影响读取。浏览器登录需要对应官方 CLI；Claude 登录或钥匙串许可可能需要用户操作。服务未提供的额度与精确 Token 不会估算补齐。

授权流程的 33 项检查、额度解析、构建及签名验证通过；Codex 已实测直接读取并在实际界面显示连接成功。Claude 的交互授权成功尚未实测。本次完整面板焦点回归未通过，桌面随后报告锁屏，仍需在解锁环境复验；本版没有修改菜单栏点击事件处理代码。

## English

### 0.7.0 · Account connections and authorized quota reads

- Added **Connect existing account**, **Browser sign-in**, **Cancel sign-in**, and **Disconnect** for Codex and Claude in **Settings → Providers**. Installed official CLIs handle browser sign-in, without manually copying tokens.
- Connected accounts query quotas, used/remaining percentages, and available reset times directly. Token totals, model details, and estimated costs continue to come from local logs.
- Direct authorized reads are opt-in per provider. Cancellation, timeouts, and disconnects reject late login completions. Changing sources clears previous quotas to prevent mixing accounts.
- Official tools retain ownership of credential storage and renewal. NowBar does not store passwords or rewrite shared credentials. Claude Keychain access can prompt only after an explicit connection action; background refresh stays noninteractive.
- Missing sign-in, expired authorization, insufficient permissions, rate limits, and unavailable quota windows have explicit states rather than being displayed as zero.
- Existing Codex CLI and Claude Desktop/status-line connections remain available. Grok Bot continues using its existing desktop session; this release does **not** add Grok Bot browser authorization.

### Install or upgrade

Download and extract `NowBar-0.7.0-macOS-arm64.zip`. Quit NowBar, replace the existing `NowBar.app` in Applications, and reopen it. Saved preferences and local history are preserved.

Requires **Apple Silicon and macOS 14 or later**. Version **0.7.0 (build 22)**. The app is ad hoc signed and is not Apple-notarized. A separate SHA-256 checksum is included. Update checks notify you of new releases; installation still requires replacing the app manually.

### Compatibility and validation

Quota endpoints are compatibility integrations and may change upstream. Browser sign-in requires the corresponding official CLI; Claude sign-in or Keychain access may require user interaction. Unavailable quotas and exact token counts are not invented or estimated from quota percentages.

The 33 authorization checks, quota parsing, build, and code-sign verification passed. A live Codex direct request and connected state in the installed UI were verified. Successful interactive Claude authorization remains unverified. The full panel-focus regression did not pass; the desktop subsequently reported a locked Mac and needs revalidation after unlock. This release does not change menu-bar click-event handling.
