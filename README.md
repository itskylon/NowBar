# NowBar

**AI 用量，抬眼可见。**

A native macOS menu bar app for AI quotas, token usage, and estimated costs.

NowBar 把 Codex、Claude 和 Grok Bot 的额度状态放进 Mac 菜单栏，并从本机日志整理 Token、模型明细与参考费用。轻点即可知道还剩多少额度、何时重置，以及今天的 AI 开发用量。

## 项目背景

同时使用多个 AI 编程工具时，查看额度通常需要反复打开各家的设置页；本机 Token、模型用量和项目开销又分散在不同日志里。NowBar 希望把这些信息集中起来，让查看用量成为一个随手就能完成的动作。

## 功能介绍

- **浅色与深色外观**：默认跟随系统，也可在通用设置中独立选择浅色或深色，切换后立即生效。
- **自动检测服务**：识别本机已安装的 Codex、Claude 桌面版或命令行版，以及 Grok Bot 桌面版；Codex、Claude 默认启用，Grok Bot 等其他已安装服务需在设置里手动开启；未安装的服务隐藏且无法启用。开关选择会保留，重新检测和重启不会重置。安装、卸载后自动更新，也可在设置中重新检测。
- **菜单栏额度**：自由选择服务、排列顺序和显示样式，支持图标、百分比、自定义组件与实时预览；查看已用、剩余百分比与重置时间。
- **快捷菜单**：右键菜单栏图标，打开用量与支出、服务状态页、设置、检查更新与关于窗口；支持 `⌘R` 刷新、`⌘,` 设置和 `⌘Q` 退出。
- **更新提醒**：启动时及运行期间每 24 小时自动检查 GitHub 稳定版，有新版时弹窗提醒；设置中也可手动检查。
- **今日用量**：展示总 Token、输入、输出、缓存读取、缓存写入和推理明细，按模型查看参考费用。
- **用量与支出**：支持 7 天、30 天、90 天、本月至今及全部历史；可选择统计时区，按提供商、项目、独立聊天或会话查看排行与模型明细。
- **历史趋势**：查看最近七天 Token / 费用趋势，以及完整历史的费用柱状图与期间明细。
- **额度提醒**：可选剩余 20%、10%、耗尽与额度重置通知，默认关闭。
- **原生体验**：额度、历史与设置使用统一的可调整大小窗口；外观与语言默认跟随系统，也可单独选择浅色、深色、中文或英文；支持可选登录时启动。

未知数据、真实零值、读取失败与过期数据会分别显示。应用不会用示例数据填充真实用量，也不会把未知费用当作免费用量。

## 支持情况

| 服务 | 账户额度 | 本机 Token 与模型明细 | 参考费用与历史 |
| --- | --- | --- | --- |
| Codex | 支持，通过已登录的 Codex CLI 读取 | 支持 | 支持 |
| Claude 桌面版 | 支持活动账户额度；Free 可读取本机缓存中的 5 小时额度 | 支持本机 Code / Cowork 会话日志；普通聊天未提供精确 Token | 日志中有实际用量时支持 |
| Claude Code | 支持，未使用桌面版时可接入状态栏 | 支持，读取本机会话日志 | 支持 |
| Grok Bot | 支持，复用本机桌面应用的活动登录 | 暂不支持 | 暂不支持 |

Claude 桌面版和 Grok Bot 的适配依赖官方桌面客户端所用接口或本机缓存，客户端变化可能影响读取。Free 账户的 Claude 查询接口未提供额度时，NowBar 会读取当前组织的桌面缓存，支持真实的 5 小时已用比例、剩余比例和重置时间。缓存随正常聊天更新，界面会显示数据来源及最后观测时间；重置后等待新数据，不自动假定用量归零。没有提供每周额度或精确 Token 时，应用显示“未提供”，不会当作零或剩余 100%，也不会通过聊天内容推算 Token。

**账户额度与本机日志是两种数据来源。** 本机用量只覆盖这台 Mac 已保存的日志，不代表其他设备或整个订阅账户；参考费用根据支持模型的 API 单价估算，不是订阅账单或实际扣费。未知模型与不支持的计价条件会标记为未计价。

## 下载安装

在 [GitHub Releases](https://github.com/itskylon/NowBar/releases/latest) 下载打包好的应用，解压后将 `NowBar.app` 拖入「应用程序」。

当前安装包适用于 **Apple Silicon（M 系列芯片）与 macOS 14 及以上**。使用本机临时签名，尚未经过 Apple 公证；首次打开如被系统拦截，可按提示在「系统设置 → 隐私与安全性」中允许打开。

### 检查更新

从 **0.6.4** 起，NowBar 会在启动时和运行期间每 24 小时检查一次新版，Mac 唤醒后会补查到期的检查。同一个新版自动提醒一次；点「稍后」后，可在主面板底部、「设置 → 通用 → 软件更新」或右键快捷菜单中再次检查。

主面板的「最近 7 天」图表下方提供用量与支出、状态页、刷新、设置、检查更新、关于和退出入口。点击外部或切换到其他应用时，菜单栏弹层会自动收起。

点击「下载更新」会打开对应的 GitHub Release 页面。下载并解压后，退出 NowBar，将新版 `NowBar.app` 替换原应用再打开；已有设置与本机历史会保留。当前不自动下载安装。**0.6.3 及更早版本需要先手动安装一次新版，才能获得更新提醒。**

## 构建与运行

需要 macOS 14 或更新版本、Xcode Command Line Tools（Swift）以及 Python 3。应用本身没有第三方 Swift 库依赖；构建脚本使用 macOS 自带的图标工具。

```sh
git clone https://github.com/itskylon/NowBar.git
cd NowBar
bash scripts/build.sh
open dist/NowBar.app
```

构建脚本按当前 Mac 架构生成应用，产物位于 `dist/NowBar.app`。当前使用本机 ad hoc 签名，尚未提供 Developer ID 签名、公证或自动安装更新。

运行回归检查：

```sh
bash scripts/test.sh
```

项目同时保留 `Package.swift` 与 XCTest 用例；脚本还包含本机日志解析、去重、计价、桥接配置及界面状态的检查。

## 数据接入与使用

1. **Codex**：安装并登录官方 Codex CLI，NowBar 自动读取账户额度与 `CODEX_HOME`（默认 `~/.codex`）中的会话日志。
2. **Claude**：先登录本机 Claude 桌面版，NowBar 自动读取当前账户的共享额度、已用比例和重置时间；可在「通用 → 额度口径」切换已用与剩余。Free 账户正常聊天后，可读取桌面缓存中的 5 小时额度，更新时间以 Claude 最后观测时间为准。系统可能提示授权读取钥匙串，应用只读登录状态和额度缓存，不修改登录信息。本机 Token 从 `~/.claude/projects/` 及 Claude 桌面端实际保存的 Code / Cowork 会话日志读取，按会话和响应去重；普通桌面聊天的精确 Token 不在该接口提供。未使用桌面版时，可在「服务接入」中安装可选的 Claude Code 状态栏桥接，收到响应后更新额度；桥接会备份原配置并保留原状态栏命令，可随时移除。
3. **Grok Bot**：先登录本机 Grok Bot 桌面应用，NowBar 读取活动账户的每周额度。系统可能提示授权读取钥匙串；应用不修改登录或凭据。

左键点击菜单栏图标打开面板，右键打开快捷菜单；图表按钮进入「用量与支出」，设置中可查看已检测的服务、重新检测安装情况，并调整菜单栏显示、刷新频率、语言与提醒。额度条旁的眼睛按钮可选择菜单栏常显项目。

全历史首次扫描可能需要时间，页面会显示读取进度。自动模式下约每 5 秒检查新增本机日志，账户额度按设置的刷新周期读取。统计只会在日志写入实际用量后更新。

演示模式使用隔离的示例数据：

```sh
dist/NowBar.app/Contents/MacOS/AgentMeter --demo
```

`AgentMeter` 是保留的内部可执行文件名。为兼容已有设置和缓存，内部模块名、bundle ID 与数据目录也保留原值；应用对外名称统一为 NowBar。

## 隐私

- 没有 NowBar 服务端，不上传本机用量历史，不调用模型生成内容。
- 账户额度使用已登录客户端或本机状态栏快照读取；必要网络请求发往对应服务的用量接口。
- 更新检查仅访问 GitHub 的 NowBar 公开发布接口，不发送本机用量、项目路径或账户凭据。演示与预览模式不检查更新。
- 日志解析用于提取用量与会话元数据，不保存对话正文；项目路径仅用于本机统计分组。
- 设置、用量缓存及 Claude 接入备份保存在本机。数据目录为 `~/Library/Application Support/AgentMeter/`；原配置备份可能包含已有敏感字段，仅保留在本机并限制文件权限。
- 通知与登录时启动默认关闭，启用后才请求相应系统能力。
